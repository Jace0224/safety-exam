# 모바일 앱으로 쓰기 (PWA)

이 폴더는 휴대폰 홈 화면에 설치해서 앱처럼 쓰는 웹앱(PWA)입니다. 한 번 인터넷으로 접속해 두면 이후에는 지하철·이동 중처럼 인터넷이 없어도 열립니다.

## 1. 폴더를 인터넷 주소(https)에 올리기

PWA는 `https` 주소에서만 설치됩니다. 아래 중 하나를 고르세요. (폴더 전체를 그대로 올리면 됩니다.)

| 방법 | 순서 | 비고 |
|---|---|---|
| Netlify Drop | Netlify Drop 페이지에 이 폴더를 끌어다 놓기 → 발급된 주소 확인 | 가장 간단. 계정을 만들어 두면 주소가 유지됩니다. |
| GitHub Pages | 저장소 생성 → 파일 업로드 → Settings → Pages에서 브랜치 지정 | 주소가 고정됩니다. |
| Cloudflare Pages | Pages에서 Direct Upload로 폴더 업로드 | 무료 플랜 사용 가능 |

## 2. 휴대폰에 설치하기

| 기기 | 방법 |
|---|---|
| Android (Chrome) | 주소 접속 → 상단 `앱 설치` 버튼 또는 메뉴(⋮) → `앱 설치`/`홈 화면에 추가` |
| iPhone·iPad (Safari) | 주소 접속 → 공유 버튼 → `홈 화면에 추가` (Safari에서만 가능) |

설치 후 홈 화면의 `안전기사` 아이콘으로 실행하세요. 설치 직후 한 번은 온라인 상태에서 앱을 열어 모든 파일이 저장되도록 해 주세요.

## 3. 알아두기

- **학습 기록(오답노트·사용자추가 문제)은 기기와 주소별로 따로 저장**됩니다. 주소를 바꾸면 기록이 새로 시작되니, 문제생성 화면의 `백업 내려받기`로 미리 백업하세요.
- `문제생성`(Claude로 정답 생성)은 인터넷과 API 키가 필요합니다. 나머지 기능(북마크, 고정 보기 포함)은 모두 오프라인에서 동작합니다.
- **고정 보기(플로팅 창)는 이 앱 화면 안에서만** 위에 떠 있습니다. 유튜브처럼 다른 앱으로 전환해도 화면에 남는 기능은 휴대폰 브라우저가 일반 웹사이트에는 지원하지 않아 만들 수 없었습니다. 이 앱을 보는 동안에는 어느 메뉴로 이동해도 계속 떠 있습니다.
- 문제 데이터를 고쳐서 다시 올릴 때는 `sw.js` 맨 위의 `CACHE = 'ise-pwa-vN'` 숫자(예: v1 → v2)를 올려야 휴대폰에 새 버전이 반영됩니다.
- iPhone은 홈 화면에 추가하지 않은 사이트의 저장 데이터를 오래 안 쓰면 지울 수 있습니다. 반드시 홈 화면에 추가해서 사용하세요.
- 문제·모의고사·퀴즈 화면의 ☆ 버튼으로 책갈피를 남기고, `북마크` 메뉴에서 모아 보거나 `📌 고정 보기`로 화면 위 창에 띄울 수 있습니다.
- 필답형·작업형·퀴즈는 정답의 핵심어를 괄호 `( )` 안 빈칸에 채워 넣는 방식이 기본입니다. 필답형·작업형 화면 위쪽의 `정답 전체보기` 버튼을 누르면 예전처럼 정답 전체를 바로 볼 수도 있습니다.
- 퀴즈는 20문항씩 5레벨로 나뉩니다. 같은 레벨이라도 메뉴에 들어갈 때마다 문제 순서가 새로 섞이고, 한 레벨의 20문항을 모두 맞혀야 다음 레벨이 열립니다. 직접 만든 [사용자추가] 문제는 레벨과 별개로 언제나 풀 수 있습니다.
- 🔊 버튼으로 문제와 정답을 음성으로 들을 수 있습니다. 휴대폰에 내장된 음성 엔진을 그대로 쓰기 때문에 인터넷이 없어도 동작하지만, 기기에 한국어 음성이 없으면 다른 억양으로 읽힐 수 있습니다.
- 필답형·작업형 화면의 `▶ 전체 듣기`를 누르면 지금 화면에 보이는 문제들을 문제→정답 순서로 이어서 들려줍니다. `★ 북마크만 듣기`를 누르면 북마크한 문제만 골라 듣습니다. 다른 메뉴로 이동해도 재생은 계속됩니다.
- 재생 중인 창의 ☆ 버튼으로 지금 듣고 있는 문제를 바로 책갈피할 수 있습니다.
- 읽는 속도는 재생 창의 `1x` 버튼을 누르면 0.75배속부터 2배속까지 순서대로 바뀝니다. `문제생성` 화면의 설정에서도 고를 수 있고, 한 번 정하면 이 기기에 계속 저장됩니다.
