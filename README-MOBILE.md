# 모바일 앱으로 쓰기 (PWA)

이 폴더는 휴대폰 홈 화면에 설치해서 앱처럼 쓰는 웹앱(PWA)입니다. 한 번 인터넷으로 접속해 두면 이후에는 지하철·이동 중처럼 인터넷이 없어도 열립니다.

## 1. 폴더를 인터넷 주소(https)에 올리기

PWA는 `https` 주소에서만 설치됩니다. 아래 중 하나를 고르세요. (폴더 전체를 그대로 올리면 됩니다.)

| 방법 | 순서 | 비고 |
|---|---|---|
| Netlify Drop | Netlify Drop 페이지에 이 폴더를 끌어다 놓기 → 발급된 주소 확인 | 가장 간단. 계정을 만들어 두면 주소가 유지됩니다. |
| GitHub Pages | 저장소 생성 → 파일 업로드 → Settings → Pages에서 브랜치 지정 | 주소가 고정됩니다. |
| Cloudflare Pages | Pages에서 Direct Upload로 폴더 업로드 | 무료 플랜 사용 가능 |

## 2. 휴대폰에 설치하기

| 기기 | 방법 |
|---|---|
| Android (Chrome) | 주소 접속 → 상단 `앱 설치` 버튼 또는 메뉴(⋮) → `앱 설치`/`홈 화면에 추가` |
| iPhone·iPad (Safari) | 주소 접속 → 공유 버튼 → `홈 화면에 추가` (Safari에서만 가능) |

설치 후 홈 화면의 `안전기사` 아이콘으로 실행하세요. 설치 직후 한 번은 온라인 상태에서 앱을 열어 모든 파일이 저장되도록 해 주세요.

## 3. 알아두기

- **학습 기록(오답노트·사용자추가 문제)은 기기와 주소별로 따로 저장**됩니다. 주소를 바꾸면 기록이 새로 시작되니, 문제생성 화면의 `백업 내려받기`로 미리 백업하세요.
- `문제생성`(Claude로 정답 생성)은 인터넷과 API 키가 필요합니다. 나머지 기능은 모두 오프라인에서 동작합니다.
- 문제 데이터를 고쳐서 다시 올릴 때는 `sw.js` 맨 위의 `CACHE = 'ise-pwa-vN'` 숫자(예: v1 → v2)를 올려야 휴대폰에 새 버전이 반영됩니다.
- iPhone은 홈 화면에 추가하지 않은 사이트의 저장 데이터를 오래 안 쓰면 지울 수 있습니다. 반드시 홈 화면에 추가해서 사용하세요.

## 음성 낭독(필답형)

- 필답형 화면 위쪽의 `▶ 전체 듣기`로 문제(와 정답)를 소리로 들을 수 있고, 각 문제의 `▶` 버튼은 그 문제부터 이어서 읽습니다.
- `속도`(0.5~2.0배)와 `목소리`, `읽기 범위`(문제+정답 / 문제만)는 이 브라우저에 저장됩니다.
- 목소리는 기기에 설치된 한국어 음성을 사용합니다. 브라우저가 성별을 알려주지 않아 Yuna·Heami·SunHi·Google 한국어 같은 알려진 이름으로 여성 음성을 우선 선택하며, 다른 음성은 `목소리` 목록에서 직접 고를 수 있습니다.
- 음성이 어색하거나 한국어 음성이 없으면 기기 설정의 음성(TTS) 항목에서 한국어 음성을 설치·선택해 주세요. iPhone은 설정 → 손쉬운 사용 → 아래 읽기 및 말하기 → 목소리 → 한국어.
- 화면이 꺼지거나 다른 앱으로 이동하면 낭독이 멈출 수 있습니다.
